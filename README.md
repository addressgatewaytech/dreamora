# Dreamora Interior Decoration W.L.L. – Website

Static website (CR No. 254750). No build step needed for hosting — deploy the folder as-is (Vercel: Framework preset "Other", no build command, output directory = root).

To change contact details or legal text, edit `CONFIG` in `build.py` and run `python3 build.py`.
Catalogue items and prices: `assets/js/catalogue.js`.
